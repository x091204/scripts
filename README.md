# scripts

A personal collection of Python and Bash scripts to automate and simplify day-to-day DevOps tasks.


## 📁 Structure

```
devops-toolkit/
├── python/       # Python scripts
├── bash/         # Bash scripts
└── README.md
```

---

## ⚙️ Prerequisites

- **Python** 3.8+
- **Bash** 4.0+
- Common tools: `curl`, `jq`, `git` (install as needed per script)


## 🚀 Usage

### Python Scripts

```bash
cd python/
python script_name.py
```

### Bash Scripts

```bash
cd bash/
chmod +x script_name.sh
./script_name.sh
```


## 📝 Notes

- Scripts are intended for personal/internal use — review before running in production.
- Tested on Linux support may vary.
